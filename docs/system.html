Recipes

Each recipe is a small text file in our own format. build.mjs turns it into a flowchart page plus JSON. A menu scales its recipes to the number of people and adds up one shopping list.

Hosting

One Cloudflare Worker serves the built files and the API at recipes.mustier.ai. The shared list lives in a Durable Object, which saves to its own built-in storage.

The page

Plain JavaScript in the browser. The name and any unsaved taps are kept on the phone. The same rules for a tap (board.js) run on the phone and the server.

Deploying

node deploy.mjs on this Mac: build, check the live list, upload with Wrangler. GitHub Actions also builds on every push, but can't deploy until a Cloudflare token is added.
