Riri's 30th: how the shared menu works

recipes.mustier.ai/riri · state lives in recipes/board.js, worker.js and recipes/menu.js

Shared by everyone one board per menu, held by the server

Shop item

Butter, eggs, baguettes…

stateDiagram-v2
  [*] --> ToBuy
  ToBuy: To buy
  ToBuy --> Sorted: tick
  Sorted --> ToBuy: untick

Cupboard or kitchen kit item

Probably at home. Missing ones join the G20 list.

stateDiagram-v2
  [*] --> NotChecked
  NotChecked: Not checked
  Have: We have it
  Missing: Missing, on G20 list
  NotChecked --> Have: tick
  Have --> NotChecked: untick
  NotChecked --> Missing: Need to buy
  Missing --> Bought: tick
  Bought --> Missing: untick

Sign-up

One per person, per shop or cooking station.

stateDiagram-v2
  [*] --> Out
  Out: Not on it
  In: On it
  Out --> In: I'll go / Join
  In --> Out: Leave

Server

Handles one change at a time, so none get lost.

stateDiagram-v2
  [*] --> Idle
  Idle: Waiting
  Check: Check against menu
  Apply: Apply, version + 1, save
  Push: Send board to every open phone
  Idle --> Check: change
  Check --> Idle: not valid, say why
  Check --> Apply: valid
  Apply --> Push
  Push --> Idle

On each phone these run side by side

Name

Asked once, remembered on the phone.

stateDiagram-v2
  [*] --> Anonymous
  Ask: Who's this? (tap held)
  Anonymous --> Ask: first tap
  Ask --> Named: pick or type name, tap goes through
  Ask --> Anonymous: dismiss, tap dropped
  Named --> Ask: change

Unsaved taps

Kept on the phone until the server has them. Sent oldest first.

stateDiagram-v2
  [*] --> Empty
  Empty: Nothing waiting
  Sending: Sending
  Retry: Not saved yet
  Empty --> Sending: tap
  Sending --> Empty: all sent
  Sending --> Retry: no signal
  Retry --> Sending: after 1-15 s, or signal back

Live connection

Hears other people's changes straight away. Pings every 15 s; silent for 20 s counts as dropped. Checks the server itself every 4 s only while not live.

stateDiagram-v2
  [*] --> Connecting
  Down: Disconnected
  Connecting --> Live
  Live --> Down: dropped or silent 20 s
  Down --> Connecting: after 1-15 s
  Live --> Paused: in background
  Paused --> Connecting: back in front

What the phone shows

Not a state machine: worked out fresh every time.

Newest board from the server, with this phone's unsaved taps applied on top.

Every board has a version number. A board older than the one the phone already has is ignored.
